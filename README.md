🌱 Agro Sustentável

Produzir hoje, preservar amanhã

Um projeto de site informativo sobre práticas agrícolas sustentáveis, combinando tecnologia, produtividade e preservação ambiental.

📝 Sobre

O Agro Sustentável tem como objetivo promover a sustentabilidade no campo, mostrando maneiras de:

Conservar o solo e manter sua fertilidade.
Usar a água de forma consciente e eficiente.
Preservar a biodiversidade e recuperar áreas verdes.
Aplicar tecnologia no campo para aumentar a produtividade com menor impacto ambiental.

O projeto é desenvolvido em HTML, CSS e JavaScript, e inclui seções de apresentação, práticas sustentáveis e um contador de impacto simbólico.--
